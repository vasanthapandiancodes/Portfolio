## 🎨 Features & Highlights

1. **Design & Aesthetics**
   - **Vibrant Tech-Green Accent**: Emerald green (`#10b981`) and cyan (`#06b6d4`) accents reflecting growth, finance, athletic energy, and modern software engineering.
   - **Theme Engine**: Seamless Dark / Light theme toggle with automatic persistence via `localStorage` and system theme fallback.
   - **Modern Glassmorphism & Ambient Lighting**: Sleek backdrop blurs, glow effects, and modern card styling.
   - **Modern Typography**: Embedded Google Fonts (`Outfit`, `Plus Jakarta Sans`, and `JetBrains Mono`).
